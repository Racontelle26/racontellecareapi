Vos souvenirs ont une voix.

Bienvenue dans l’aventure ! Pendant quelques semaines, votre famille teste Racontelle avant tout le monde. Trois étapes pour commencer, puis six petites missions à relever ensemble.

Étape 1

Installer l’application

Le lien de téléchargement vous est envoyé par message. Ouvrez-le directement sur votre téléphone Android, pas sur un ordinateur.
  1. Touchez le lien, puis Install (ou Télécharger). Le fichier Racontelle se télécharge.
  2. Ouvrez le fichier téléchargé (dans la notification, ou dans Fichiers → Téléchargements).
  3. Le téléphone demande d’autoriser l’installation depuis cette source ? Touchez Paramètres, activez l’interrupteur, puis revenez en arrière. C’est normal : l’application n’est pas encore sur le Play Store.
  4. Touchez Installer. Si Play Protect s’inquiète, choisissez Plus de détails → Installer quand même.
  5. Le R rose de Racontelle apparaît parmi vos applications. Touchez-le : c’est parti !
Sur iPhone ? Pas encore disponible pendant cette bêta. Vous pouvez raconter sur le téléphone Android d’un proche : chaque souvenir est attribué à la personne qui parle.

Étape 2

Se retrouver en famille

  1. Créez votre compte : Créer mon espace famille, puis votre prénom, votre e-mail et un mot de passe. L’œil à côté du mot de passe permet de vérifier ce que vous tapez.
  2. Une seule fois ! Ensuite l’application se souvient de vous : plus besoin de vous reconnecter. Votre e-mail reste pré-rempli si jamais vous vous déconnectez.
  3. La personne qui lance la famille touche Créer, donne un nom (« La famille Martin ») et peut ajouter jusqu’à trois proches sans e-mail, par exemple Papi qui n’a pas de smartphone.
  4. Les autres proches reçoivent une invitation par e-mail avec un code. Ils créent leur compte, touchent Rejoindre et tapent le code.
  5. Autorisez le micro la première fois qu’on vous le demande. Sans lui, pas de voix !
Avant d’enregistrer quelqu’un, demandez-lui son accord : ses souvenirs seront partagés avec toute la famille, et personne d’autre.

Pas de panique

Petits secours

Le micro ne marche pas.
Sur l’écran d’enregistrement, touchez Ouvrir les réglages et autorisez le micro pour Racontelle.
J’ai supprimé un souvenir par erreur ?
Impossible sans le vouloir : l’application vous demande toujours de confirmer avant de supprimer.
Mon souvenir ne part pas.
Le réseau est faible ? L’écran affiche « En attente d’envoi » et garde votre enregistrement. Touchez Réessayer l’envoi quand le réseau revient.
Je ne vois pas le souvenir de ma sœur.
Tirez l’écran vers le bas pour l’actualiser.
Mon code d’invitation ne marche pas.
Il est valable 7 jours. Demandez à la personne qui a créé la famille de vous le renvoyer.
J’ai oublié mon mot de passe.
Mot de passe oublié ? sur l’écran de connexion : un code arrive par e-mail.
Qui peut écouter nos souvenirs ?
Seulement les membres de votre famille dans Racontelle. Personne d’autre.
